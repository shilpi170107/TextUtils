# TextUtils - Text Manipulation App

TextUtils is a text manipulation web application built using **React.js and Bootstrap**. It provides a simple and user-friendly interface to perform various text operations.

## 🚀 Features

- Convert text to Uppercase.
- Convert text to Lowercase.
- Clear text content.
- Count total words and characters.
- Calculate estimated reading time.
- Preview entered text.

## 🛠️ Tech Stack

- React.js
- Bootstrap
- HTML5
- CSS
